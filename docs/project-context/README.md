## Filosofía

En PAMPA la documentación forma parte del producto.

Toda decisión importante deberá:

1. Analizarse.
2. Documentarse.
3. Aprobarse.
4. Implementarse.

Nunca se implementará una funcionalidad importante sin que exista documentación previa.

---

## Arquitectura

La carpeta `architecture/` contiene los ADR (Architecture Decision Records).

Cada ADR documenta:

- Contexto
- Problema
- Decisión
- Justificación
- Consecuencias
